# Build 20.1 R03: OSRS Wiki "/Strategies" equipment tables transcribed slot by slot, read 2026-11-01.
# Format: one BOSS block; per SETUP each slot lists the Wiki table columns left-to-right, best first,
# separated by " > ". Alternatives inside one column are separated by " / ". "N/A" = the Wiki cell is empty.
# Tiers are taken by column: OPTIMAL = first column, RECOMMENDED = middle column, ENTRY = last column.
# A weapon cell that is N/A falls back to the nearest better column (a weapon is never left empty).
# "[task]" = Slayer-task-only item: skipped for the next column. "[generic]" = the Wiki names no item: left empty.
# Two-handed weapons empty the shield slot. "[any] X" = the Wiki says any of a family (e.g. any god cape); X is shown and noted.
# INV lines: "Item xN" (N = stated count or the lower bound of a stated range; "xNs" = one stack of N); "FILL Item" fills every
# remaining slot (Wiki "rest food"). Items the Wiki names only generically are left out and noted.
