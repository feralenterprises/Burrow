# TrashPanda Tracker R10C · 225px visual review shell

**STANDALONE RELEASE HOLD.** This is not the RuneLite plugin. No main TPT source, bank, player, or event data were altered.

Run `00-OPEN-UI-SHELL-WINDOWS.cmd` after extracting the whole ZIP. Requires Java 17 or newer.

Go to **Boss Chronicle** and select **Compare** to show the 3 boss portrait crops from the original owner-approved design screenshot; select **Sprites** to return to authentic small OSRS sprites. Screenshot crops are NOT authenticated game models and cannot satisfy the artwork acceptance gate. The rest of the shell is unchanged.

Run `02-VERIFY-UI-SHELL-WINDOWS.cmd` for isolated controls and art-gate tests. Use `05-RENDER-SWING-PREVIEWS-WINDOWS.cmd` for genuine Swing captures.

The file `previews-reference/` contains special *design comparison* captures and `previews/` contains the untouched genuine-sprite default; both are at 225px with enlarged phone images.
