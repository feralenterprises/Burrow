## Art slot contract

Standalone extracted root: `assets/verified-models/{scurrius,sarachnis,bryophyta}-model.png`. PNGs >= 128 px on each side will be displayed in corresponding gallery and detail portrait frames; otherwise the genuine small OSRS sprite remains. Review each source URL and rights before distribution and get owner sign-off. Do NOT put files in the main plugin without a separate approval.

The 'OSRS sprite' text in the current preview is intentional honesty, not a finished graphical choice. All three image fidelity issues remain OPEN.
