# Owner artwork acceptance criteria for a future checkpoint

1. Boss identity: each image is the real in-game OSRS Scurrius, Sarachnis, or Bryophyta model, not AI art, concept art, another RS game, an item icon, a stretched 15px sprite, or a fan-site derivative.
2. Portrait: suitable transparent full-body game model render with the needed orientation; at least 128x128 PNG (prefer 256+).
3. Source/permission: retain original URL or locally captured game source, permissions/redistribution note, date and original file checksum.
4. Owner explicitly approves each portrait. Record `owner_approved=true` *only after* viewing it.
5. Manifest entries must include source_url, rights_note, sha256, and owner_approved. Manifest checks are record/integrity checks, **not** a way to prove authenticity or legal permission.
6. Run `03-CHECK-ARTWORK-STATUS-WINDOWS.cmd`, then launch shell; screenshot at 225px in gallery and detail and obtain owner signoff.
7. Preserve four tabs, 11-slot gear and 4x7 inventory, independent boss selections, bank no-live-data rules.
8. Leave the main TPT plugin untouched until integration review.
