Nothing from a third-party PNG mirror was bundled or passed off as official game art. On the owner's Windows machine, the standalone reviewer now supports in-app **Fetch OSRS Wiki** for each boss; this is a genuine attempt to fetch `File:<Boss>.png` original via the MediaWiki imageinfo API. File presence, identity, source, and rights still require review. The importer stages UNAPPROVED bytes only. There are no approved full-size boss models in this deliverable.

Wiki image naming policy: https://oldschool.runescape.wiki/w/RuneScape:Images_and_media_policy
Boss pages: https://oldschool.runescape.wiki/w/Scurrius ; https://oldschool.runescape.wiki/w/Sarachnis ; https://oldschool.runescape.wiki/w/Bryophyta

The wiki may deny access or use a different original filename; a failed import is expected to be non-destructive. It also may return an image that is **not** a desired full-body model despite meeting PNG tests. Visual identity and usage-rights review remain mandatory.
